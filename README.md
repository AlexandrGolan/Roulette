Roulette CLI game


Build:

`cd Roulette`
`make`

How to play:

1.Run the roulette binary

2.Initially,you have 1,000 TuxBucks in the BID field enter the desired bet amount,for example, 100

3.After entering the bet,use the arrows to select the desired bet option (navigating the field may not work correctly,sorry in advance.)

4.Wait the result


(If your balance is 0, the game will end. To play again, run the binary file again and the game will start over. If you exit the game with Ctrl+c, the process will not be saved; the game does not have a function for saving progress)
